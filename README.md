Institutional Risk & CapEx Forecasting Tool

Overview

The Institutional Risk & CapEx Forecasting Tool is a Python-based risk assessment application designed for private equity sponsors, commercial lenders, and capital decision-makers. It evaluates portfolio companies to forecast capital intensity, cash burn, and the probability of debt covenant breaches over a predefined time horizon.

run (pip install yfinance pandas pandas-datareader statsmodels xgboost numpy) through your CLI to run the program
