to an Asset-Based Lending (ABL) proxy, strictly defining the revolver capacity as 10% of the 
company's Total Book Value.

Specific Updates:

Dictionary Restructure: Added a book_value key to the hardcoded portfolio_companies dictionary.

API Ingestion (yfinance):

Added logic to fetch bookValue (per share) and sharesOutstanding.

Logic Overhaul:

Replaced the old formula (Leverage * EBITDA) - Net Debt with Total Book Value * 0.10 in 
view_companies(), add_update_company(), and refresh_live_data().

User Interface: Added manual fallback prompts for Book Value if API data is missing, and updated
 all print statements to reflect the new "10% Book Value" methodology.
